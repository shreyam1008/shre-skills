# Catalog and skill review — 9 September 2026

Reviewed the live catalog, all 21 SKILL.md files, installation paths, generated
metadata, hosting records, and CI. Corrected 17 skills; retained the existing
guidance in `git`, `html`, `web-performance`, and `low-level-web-rendering`.
This is an update to `main`, not a new CalVer release.
